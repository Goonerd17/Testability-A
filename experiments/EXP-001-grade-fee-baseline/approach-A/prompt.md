## Turn 1 (사용자 → AI, 2026-10-12)

# Phase 3 — 실험 A: Claude 단독 테스트

## 목표

Claude가 비즈니스 코드와 업무 명세만 보고 테스트 대상을 선정하고 단위 테스트를 작성한다.

## 입력

- Phase 2 최초 구현 코드
- Phase 1 업무 명세
- EXPERIMENT_SCOPE.md

## 작업

1. 테스트가 필요하다고 판단한 메서드를 선정한다.
2. 선정 이유를 설명한다.
3. JUnit 5와 AssertJ로 단위 테스트를 작성한다.
4. 정상값, 경계값, 잘못된 입력을 검증한다.
5. 실제 테스트를 실행한다.
6. JaCoCo Line / Branch Coverage를 측정한다.

## 제약

- Jev 사용 금지
- 테스트 필요 점수 산출 금지
- 최초 비즈니스 코드 수정 금지
- 기존 명세와 다른 기대값을 임의로 사용하지 않는다.
- 실패한 테스트를 삭제하거나 기대값을 변경하지 않는다.
- 실험 범위 밖의 환불, DB, API 테스트는 작성하지 않는다.

## 결과

다음 항목을 기록한다.

- 테스트 메서드 수
- 검증한 업무 규칙
- 테스트 성공/실패
- 발견한 실제 버그
- Line / Branch Coverage
- 작성하지 않은 테스트와 그 이유

실험 A의 코드와 결과를 별도 브랜치에 보존한다.
